# 🍔 Bites Up Restaurant App UI/UX Design

Bites Up is a modern restaurant mobile application UI/UX prototype designed in Figma.  
The application provides users with an easy and interactive food ordering experience including:

- 🍗 Online Food Ordering
- 🛵 Delivery Tracking
- 🍽️ Dine-In Token System
- 🔔 Live Notifications
- 🛒 Smart Cart Management
- 🌙 Dark Theme Modern UI

The project is focused on improving customer experience with visually appealing interfaces and smooth user interaction.
